# The Scent Atelier 
Curating timeless scents for modern romantics

The Scent Atelier is a luxury-themed fragrance website curating premium designer perfumes and ouds for both men and women. The project focuses on elegant UI design, smooth animations, and a premium brand aesthetic inspired by high‑end fragrance houses.

## Brand Identity & Design
The Scent Atelier uses a refined visual language:
- Gold gradients
- Rose-gold accents
- Black backgroud
- Shimmer animation
- Soft fade-in transitions
- High quality product images

## Key Features
- Monogram, brand name visible across all pages. 
- Product pages for Men, Women and All.
- Clean navigation across all pages.
- Luxury typographyand gradients
- Responsive pages, site uses a dual style-sheet:
      mobile.css and desktop.css for its pages to ensure the layout adapts smoothly across devices.

## Technology Used
- HTML
- CSS
- JavaScript

##  Requirements To Run The Project

To run the project locally, you only need:

    - A modern web browser like Chrome, Edge or Safari
    - A simple local server (optional)

## How to Run the Project

    Option 1 — Open the site directly, fast and works for most features.
        1. Navigate to the "pages" folder  
        2. Double‑click "index.html" 
        3. The site will open in your browser

    Option 2 — Run using a local server, to ensure file paths behave consistently, images load correctly, JavaScript runs without restrictions and cart system works reliably

        - VS Code Live Server 

            1. Install "Visual Studio Code"
            2. Install the extension "Live Server"
            3. Open your project folder in VS Code
            4. Right‑click "index.html"
            5. Select “Open with Live Server”
